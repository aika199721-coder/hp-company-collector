# Phase 11.2.2.2: PowerShell候補配列

## 修正内容

`Add-PythonCandidate`の`Candidates`引数へ`AllowEmptyCollection`を指定し、空の`ArrayList`を最初の候補追加へ
渡せるようにする。`Get-PythonCandidates`は候補オブジェクト以外をsuccess pipelineへ出力せず、候補を
配列として返す。`Find-Python313`は`@(Get-PythonCandidates ...)`で必ず配列化してから列挙する。

候補0件の場合はparameter binding errorにせず、`Python 3.13候補が見つかりません`を表示して利用者
エラーへ進む。`Get-Command python.exe`では`Source`を優先し、必要なら`Path`を使用するため、GitHub
Actionsのhosted toolcacheにあるPythonを候補へ確実に追加できる。

## Release gate

Windows setup smokeが日本語、空白、括弧、OneDrive相当の全パスでsetup、validate、setup再実行に成功する
までrelease Artifactを公開しない。既存の`windows-release`から`windows-setup-smoke`への依存を維持する。
