# Phase 11.2.2.1: Windows Python検出

## 検出順序

Windows setupは`HPCC_PYTHON`、`Get-Command python.exe`、`where.exe python`、`pythonLocation`、
`Python_ROOT_DIR`、`.venv`、`py -3.13`、`python`、`python3`の順に候補を検査する。各候補は実際に
短いPythonコードを実行し、実行ファイル、version、bit数を確認する。64bit Python 3.13だけを採用し、
3.12、32bit、実体のないパス、WindowsAppsのMicrosoft Store aliasは除外する。

GitHub Actionsでは`actions/setup-python`の`python-path` outputを`HPCC_PYTHON`へ設定する。setupログには
PATH、where結果、Get-Command結果、setup-python path、全候補のprobe結果、最終採用path、version、bit数を
保存する。

## Smoke gate

日本語、空白、括弧、OneDrive相当の4パスすべてでsetup、validate、setup再実行が終了コード0になることを
release Artifact公開の必須条件とする。smoke summaryには使用した`HPCC_PYTHON`と各パスの終了コードを
記録する。release jobがsmoke jobへ依存するgateは維持する。
